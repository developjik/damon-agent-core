# damon-relay deploy pack

Everything a fresh server needs to run your relay — generated by
`damon-relay --deploy-pack <dir>`. Pick ONE of the two paths below.

## 0. Common first steps

1. Copy this folder to your server (any Linux x86_64/arm64 VPS works):
   `scp -r . user@your-server:~/relay-pack`
2. Generate a registration secret and keep it once:
   `openssl rand -hex 32`
3. Open the relay port (default 8080/tcp) in your firewall/security
   group.

## 1a. systemd path

```sh
sudo cp damon-relay /usr/local/bin/            # the binary you copied in
sudo mkdir -p /etc/damon && sudo cp relay.env /etc/damon/relay.env
sudo nano /etc/damon/relay.env                 # paste your DAMON_RELAY_SECRET
sudo cp damon-relay.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now damon-relay
systemctl status damon-relay                   # should be active (running)
```

## 1b. Docker path

```sh
cp damon-relay .            # the binary must sit next to the Dockerfile
nano relay.env              # paste your DAMON_RELAY_SECRET
docker compose up -d
docker compose logs -f relay
```

## 2. Point your daemon at it

On the machine running `damond`, add to the daemon's config
(see `daemon.example.toml` here):

```toml
[relay]
url = "ws://your-server:8080"
name = "my-daemon"
secret = "env:DAMON_RELAY_SECRET"
```

then set `DAMON_RELAY_SECRET` (the SAME value) in the daemon's
environment and restart `damond`.

## 3. Use it

Open `http://your-server:8080/` in a browser (phone or laptop), enter
the daemon name and the daemon's auth token — the page connects back
through the relay end-to-end encrypted. The relay sees ciphertext
only; it never holds your daemon token.

## Security notes

- Traffic through the relay is E2E-encrypted (X25519 + AES-256-GCM);
  the relay cannot read it. `DAMON_RELAY_SECRET` only gates which
  daemons may register — set it so nobody else can host tunnels on
  your server.
- Prefer TLS in front (Caddy/nginx/your VPS panel) for browser
  access; `wss://` works through the same port.
