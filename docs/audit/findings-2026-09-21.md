# Audit Findings — Remediation

## 2026-09-21 — Remediation of the 2026-09-21 audit (ACP-centric daemon)

- 대상: damon-agent-core (Rust 크레이트 `damon-core` + npm/python 클라이언트 + 테스트 + CI)
- 방식: 11개 검증 에이전트의 확인 finding을 파일 소유권 기준 7개 수정 패키지로 병렬 리미디에이션 → 오케스트레이터 통합/검증

### 수정 완료 (High)

| # | 항목 | 수정 |
|---|------|------|
| H1 | `fs/*` 역방향 요청이 임의 경로 R/W 허용 | `AgentProcess::session_cwds` + `resolve_in_session_cwd`: canonicalize 후 세션 cwd prefix 검사, 미등록 세션/`..`·symlink 탈출 거부, 읽기 8MiB 캡. `session/new`·`resume`·`fork`에서 cwd 등록 |
| H2 | stale `acp_sessions` 엔트리가 dead 프로세스에 영구 매핑 | 맵이 `(agent_id, agent_session, pid)` 보관; `run_turn`/`session_resume` warm-cache가 pid 비교 후 stale 제거 |
| H3 | `read_loop`가 permission pump를 `await`해 stdout 읽기 정지 | 역방향 요청을 `tokio::spawn`으로 디스패치 — writer mutex만 응답 직렬화 |
| H4 | `read_loop` EOF가 `child.wait()`를 `await`해 shutdown과 교착 | `child.try_lock()`으로만 reap; `reap_idle`/`refresh`는 맵 락 해제 후 `shutdown().await` |
| H5 | `require_token` fail-open — 미설정 토큰이 `/metrics` 등 노출 | 비-loopback bind에서 토큰 미설정/미해석 시 503 (fail-closed) |
| H6 | 릴레이 E2E base64 팽창으로 4MiB 프레임 초과 | `MAX_RESPONSE_BYTES` 3,000,000으로 하향 + `E2e::encrypt`가 초과 plaintext 명시 거부(양방향) |
| H7 | non-TLS graceful shutdown 미바인딩 | plain 경로도 `axum_server::from_tcp` + `Handle::graceful_shutdown(5s)`; bind→discovery::write→serve 순서 통일 |
| H8 | CI `$base` 미정의 — formula 다운로드 실패 | `base="https://github.com/${{ github.repository }}/releases/download/${GITHUB_REF_NAME}"` 추가 |

### 수정 완료 (Medium, 발췌)

- `acp.rs` stdout/stderr: `read_capped_line` — stdout 4MiB 라인 캡(초과분 폐기), 라인별 UTF-8 검사(InvalidData 스킵), stderr 8KiB 절단
- `acp.rs` 비-u64 응답 id 무시 (`unwrap_or(0)` 제거 — id 0 요청과의 오매칭 방지)
- `agents.rs` `INIT_TIMEOUT_NPX` 300s (npx 어댑터 첫 실행 다운로드), Windows `.cmd/.bat`는 `cmd.exe /c` 경유
- `damon-relay.rs` disconnect 통지를 5s timeout bounded send로 — 데몬 세션 슬롯 누수 방지
- `relay.rs` disconnect 프레임을 3개 세션 종료 경로 모두에서 전파 (decrypt 실패/백프레셔/중복 connect 교체)
- `client.rs` `drain_pending`을 writer 교체 직후 재호출 — dead sink에 보낸 waiter의 영구 대기 해소
- `relay.rs` 터널 keepalive: 30s Ping + 120s 무수신 시 재접속 (relay/daemon 양쪽)
- `relay.rs` `env:`/`keychain:`/`!` 형태의 malformed secret ref를 fail-closed (literal fallback 제거)
- `rpc.rs` `session/prompt`의 `model` 파라미터 제거 — Rust/npm/python 클라이언트 전부 갱신, silent no-op 제거
- `rpc.rs` `tool_call`/`agent_thought_chunk`를 `replay_updates` 호환 형태로 영속화 — `session/load` 재생 가능
- `config.rs` `STARTER_CONFIG` 톱레벨 키를 테이블보다 앞에 배치 — 주석 해제 시 잘못된 테이블 귀속 방지
- `config.rs` `ensure_config` 0600 atomic create (TOCTOU 제거) + 느슨한 권한 경고
- `api.rs` `ws_tickets` insert 시 TTL sweep — 미사용 티켓 영구 누적 제거
- `api.rs` rate_buckets 10분 eviction, SSE lagged named event, 비-loopback `/health` 최소화
- `damon.rs` `--url` 미지정 시 `~/.damon/daemon.json` discovery로 live 데몬 자동 접속
- `python/client.py` `urlopen` 15s timeout; `npm/client.mjs` ticket fetch `AbortSignal.timeout(15000)` + `respondError` 추가
- `discord.rs` connect/hello 30s timeout; `slack.rs` ack 전 `incoming_from_event` 해석; Discord/Slack 첨부 전용 메시지에 "미지원" 안내
- `telegram.rs` document → `Attachment::TelegramFile` 매핑 + 미지원 타입 안내
- `channel.rs` permission timeout을 `initialize`의 `permissionTimeoutSecs`로 (300s fallback)
- `ui.html` WS onclose가 pending reject, `loadMessages`가 'frame cap' 에러 시 페이지네이션, 첨부 2.5MB 캡
- `ui.rs` CSP + nosniff 헤더 (inline script용 `script-src 'unsafe-inline'` 포함)
- `store.rs` `tighten_permissions` pub(crate) + backup 0600, `ORDER BY created_at,id` tiebreak, `messages_paged` compaction cutoff, dead API(`session_model`/`set_session_model`/`set_compaction`/`compact_session`) 제거
- `damond.rs` `println!` → EPIPE 안전 `outln`/`out`, `--token` argv 경고, `resolve_command` 10s timeout, relay hot-reload 미지원 경고
- `config.rs` reload 시 `.env` 재주입 차단 (`load_no_env` — `unsafe set_var` 제거)

### 잔여/후속

- `session/prompt`의 `model` 제거는 wire-breaking 변경 — npm `damon-agent` 클라이언트와 데몬 버전이 엇갈리면 구형 클라이언트의 `model` 필드는 무시됨(에러 아님). 릴리스 노트에 명시 필요.
- `run_turn`의 `model` 파라미터는 CLI에서 제거했으나 `new_session(cwd, model)`의 agent 선택 의미는 유지 — `--model` 플래그명은 `Chat`/`Prompt`에서 agent id를 받으므로 향후 `--agent`로 rename 검토.
- relay `disconnect` 프레임은 relay 측 `recv_task`가 owner 검증 후 처리 — 구형 relay(무시)와의 하위호환 유지.
