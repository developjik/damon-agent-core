AI 코딩 도우미를 한 자리에 모아 관리하는 로컬 프로그램의 기능을 소개합니다.

Damon이 무엇인가요?

요즘 AI 코딩 도구는 여럿입니다. Claude Code, Codex, Qwen Code처럼 터미널에서 돌아가는 도구들이 각자 따로 설치되어 있고, 대화도 따로 관리됩니다. Damon은 이런 도구들을 한데 묶어 주는 관제 프로그램입니다.

  • 설치·로그인되어 있는 도구를 알아서 찾아 연결합니다. Damon 쪽에서 추가로 입력할 것은 없습니다.
  • 웹 브라우저, 텔레그램, 디스코드, 슬랙, 터미널 어디서 접속해도 같은 대화를 이어갈 수 있습니다.
  • 지나간 모든 대화가 기록되고, 나중에 검색으로 다시 찾을 수 있습니다.

이름의 유래: 유닉스에서 뒤에서 조용히 늘 도는 프로그램을 daemon(데몬)이라고 부릅니다. Damon은 그 말장난이면서 실제 모습이기도 합니다. 컴퓨터 안에서 상시 대기하며 사용자와 AI 도구 사이를 이어 줍니다.

역할 분담이 이 구조의 핵심입니다. 모델 고르기, 도구 쓰기, 로그인 인증, 대화 맥락 관리는 전부 각 AI 도구의 몫입니다. Damon은 사용자가 마주하는 부분 — 대화 창, 기록, 승인, 원격 접속 — 만 책임집니다. 덕분에 Damon 설정에 API 키를 넣을 일이 없습니다.

1.AI 코딩 도우미 9종, 설정 없이 통합 구동

Damon을 켜면 설치되어 있는 CLI를 스스로 찾아 등록합니다. 로그인 상태와 모델, 도구 설정은 그대로 물려받습니다. 지원하는 도구는 Claude Code(Anthropic), Codex CLI(OpenAI), Oh My Pi, Pi, Qwen Code(Alibaba), Droid(Factory), OpenCode, MiMo, ZCode(Z.ai) 아홉 가지입니다.

2.어디서나 대화 — 접속 창 여섯

Damon 본체 하나에 여러 창이 동시에 붙을 수 있습니다. 사무실에서는 웹으로, 이동 중에는 텔레그램으로 같은 대화를 이어갑니다.

접속 창여는 방법특징
웹 UI브라우저에서 http://127.0.0.1:9470/ui설치가 필요 없습니다. 답변이 실시간으로 흘러나오고 코드에 색이 입혀집니다.
터미널 CLIdamon chat한 줄 질문은 damon prompt로도 보낼 수 있습니다.
텔레그램damon-telegram 실행허가 요청이 버튼으로 도착합니다.
디스코드damon-discord 실행채팅방마다 다른 대화가 자동으로 배정됩니다.
슬랙damon-slack 실행버튼형 허가 승인을 지원합니다.
직접 만든 앱Rust · Node.js · Python 라이브러리기능 11에서 다룹니다.
채팅 앱에서는 채팅방마다 대화가 하나씩 배정되고, 채팅방에 올린 파일이 질문에 함께 전달됩니다. 답변은 도착하는 대로 조금씩 흘러나옵니다.

3.허가 승인 — AI가 뭘 하기 전에 물어봅니다

AI가 파일을 고치거나 명령을 실행하기 전에 "해도 될까요?"라고 묻는 경우가 있습니다. Damon은 이 질문을 지금 열려 있는 어느 창으로든 전달하고, 답을 다시 AI에게 전합니다.

  1. 사용자 — "이 버그 좀 고쳐줘"
  2. Damon — AI 도우미에게 작업을 전달합니다.
  3. AI 도우미 — "test.sh를 실행해도 될까요?" 하고 물어옵니다.
  4. Damon — 지금 켜 놓은 창(웹, 텔레그램, 슬랙 등)에 승인 버튼을 띄웁니다.
  5. 사용자 — 허용, 거절, 이번 대화 전체 허용 중 하나로 답합니다.
  6. AI 도우미 — 답을 받아 작업을 계속하고, 결과는 실시간으로 흘러나옵니다.
5분(기본값, 변경 가능) 동안 답이 없으면 자동으로 거절됩니다. 방치해도 안전합니다.

텔레그램에서 시작한 작업의 허가 요청에 웹에서 답할 수도 있고, 그 반대도 됩니다. 어느 창이든 같은 방식입니다.

5.대화(세션) 관리

하나의 대화 덩어리를 세션이라고 부릅니다. Damon은 세션을 문서처럼 다룰 수 있게 해 줍니다.

기능설명
이어하기 (resume)재부팅 후에도 대화 맥락이 그대로 복원됩니다.
포크 (fork)지금까지의 기록을 복사해 새 대화로 분기합니다. 원본은 그대로 남습니다.
가져오기 (import)Damon 없이 AI 도구를 직접 쓰던 때의 옛 대화를 찾아 등록합니다.
지켜보기 (watch)다른 화면에서 돌고 있는 대화의 종료·허가 요청을 이 채팅으로 알려 줍니다.
끊김 없는 작업 (detach)폰을 잠그거나 네트워크가 바뀌어도 시켜 둔 작업은 계속 진행됩니다.
중간 지시 (steer)진행 중인 작업에 "그리고 이것도 확인해 줘"를 덧붙일 수 있습니다.
이름 · 고정 · 태그 · 보관중요한 대화를 분류해 둡니다.
모델 · 모드 전환대화 도중에도 AI 모델과 허가 수위(예: 읽기 전용 모드)를 바꿉니다.
자동 정리잠들어 있는 도구는 30분 뒤 닫힙니다. 대화 기록은 유지됩니다.

6.프로젝트와 워크트리 — PR 하나, 에이전트 하나

여러 작업을 동시에 벌일 때 코드 사본이 섞이면 곤란합니다. Damon은 GitHub의 PR(풀 리퀘스트, 코드 병합 요청) 하나당 격리된 작업 공간을 만들어 줍니다.

그림 4. 워크트리 생성 — "PR 123번 코드 검토해 줘" 한 마디로 시작합니다.
  • PR 번호 123, #123, PR 링크 어느 것이든 이해하고, gh 도구가 설치되어 있으면 PR 제목과 상태까지 미리 보여 줍니다.
  • 같은 PR을 다시 요청하면 이미 만든 공간을 그대로 재사용합니다.
  • 대화가 붙어 있는 작업 공간은 제거 요청을 거부합니다. 실수로 지워지는 일이 없습니다.
  • 프로젝트 기능으로 폴더별 기본 도구·모델·모드를 정해 두면 그 폴더의 새 대화에 자동으로 적용됩니다.

8.집 밖에서도 접속 — 원격 접근 세 가지

Damon은 내 컴퓨터에서 돌기 때문에 기본적으로는 같은 네트워크에서만 접속됩니다. 밖에서 접속하려면 다음 중 하나를 씁니다.

  • Tailscale — 가장 쉽고 권장되는 방법. 가상 사설망으로 내 컴퓨터에 직접 연결하며 Damon 설정은 바꿀 것이 없습니다.
  • 직접 TLS — Damon이 암호화 통신(wss)으로 직접 문을 열어 줍니다. 접속 토큰이 필수입니다.
  • 중계 서버 (damon-relay) — 공개 서버 하나를 빌려 Damon이 밖으로 먼저 연결합니다. 내 컴퓨터는 문을 열 필요가 없습니다.

중계 서버 주소를 브라우저로 열면 웹 대화창이 바로 뜹니다. 앱 설치나 VPN 설정이 필요 없고, 세 방법 모두 결국 같은 Damon에 도착하므로 집 컴퓨터의 대화를 폰에서 이어볼 수 있습니다.

9.안전장치

내 컴퓨터에서 AI가 파일을 만지는 구조이므로 안전장치가 여러 겹으로 들어 있습니다.

장치하는 일
접속 토큰외부 접속에는 반드시 토큰이 필요합니다. 없으면 애초에 실행을 거부합니다.
폴더 허용 목록에이전트가 작업할 수 있는 폴더를 미리 제한합니다.
허가 질의위험한 작업 전에 반드시 사용자 승인을 받습니다. (기능 3)
허가 시간 제한답이 없는 허가 요청은 5분 뒤 자동 거절됩니다.
요청 횟수 제한외부 접속에는 분당 요청 수 제한이 걸립니다.
비밀번호 보관설정 파일에 비밀 키를 직접 쓰지 못하게 하고, 환경변수나 macOS 열쇠고리 참조만 허용합니다.
파일 접근 한정원격에서 파일을 읽고 쓸 때 그 세션의 작업 폴더 밖으로 나가지 못합니다.
암호화 통신원격 연결은 종단간 암호화입니다. 중계 서버도 내용을 볼 수 없습니다.

  • 유휴 도구 정리(30분), 오래된 세션 정리(보존 기간), 동시 세션 수 상한을 설정할 수 있습니다.
  • 상태 확인: 실시간 로그(damon logs), 연결 점검(damon doctor), 지표(/metrics), 생존 확인(/health).
