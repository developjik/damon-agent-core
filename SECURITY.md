# Security Policy / 보안 정책

## Supported Versions / 지원 버전

| Version | Supported |
| ------- | --------- |
| latest release | ✅ |
| older versions | ❌ |

## Reporting a Vulnerability / 취약점 신고

**가장 빠른 경로: 이 리포의 [Security 탭](../../security) → "Report a vulnerability"** (GitHub Private Vulnerability Reporting)

- Email: developjik@gmail.com
- 응답 목표: 7일 이내 확인, 30일 이내 수정 계획 공유
- 신고 내용은 비공개로 다루며, 수정 후 릴리스 노트에 기여 크레딧을 남깁니다(원하는 경우).
- The fastest route is this repository's **Security tab → "Report a vulnerability"**. Reports are handled privately; expect acknowledgment within 7 days and a fix plan within 30 days.
