Damon은 Claude Code·Codex CLI·Oh My Pi를 네이티브 CLI로 구동하는 Rust 상주 데몬입니다. 모델·툴·인증은 에이전트 몫 — Damon은 세션, 권한 릴레이, 검색 가능한 히스토리, 채팅 채널, 원격 접근을 소유합니다.

설치 npm install -g damon-agent

왜 Damon인가

에이전트는 그대로, 제어는 한 곳에서

이미 에이전트 CLI를 구독 중이라면 설정할 게 하나도 없습니다. Damon은 설치된 CLI를 감지해 로그인과 툴을 그대로 물려받습니다.

설정 없는 백엔드

PATH의 claude·codex·omp를 자동 등록합니다. 다른 에이전트도 [backends.X] 블록 하나면 연결됩니다.

권한은 당신 채널로

에이전트의 권한 요청을 웹 UI·CLI·텔레그램/디스코드/슬랙의 allow/deny 답장으로 릴레이합니다.

검색 가능한 히스토리

모든 대화가 SQLite + FTS5에 기록됩니다. damon search "error timeout"으로 전체 이력 전문 검색.

채팅 채널 내장

Telegram·Discord·Slack 어댑터가 별도 바이너리로 제공됩니다. 채팅별 세션 자동 매핑, 스트리밍 응답.

시크릿은 Damon에 없다

에이전트가 자기 인증을 관리합니다. Damon config는 포트와 토큰 정도뿐.

어디서든 접근

wss 직접 서빙 또는 damon-relay 아웃바운드 터널 — X25519 + AES-256-GCM E2E 암호화.

상주하도록 설계

Rust 데몬 본체는 가볍게 유지됩니다. 에이전트 프로세스는 에이전트의 몫입니다.

아키텍처

퀵스타트

3줄이면 충분합니다

설치 
$ npm install -g damon-agent   npm (프리빌트 바이너리)
$ cargo install damon-core       crates.io
$ brew install developjik/tap/damon  Homebrew tap
실행 
$ damond    첫 실행 시 스타터 config 생성
$ damon doctor  어떤 백엔드가 설치됐는지 확인
확인 
$ curl localhost:9470/health
{"backends":["claude","omp"],"status":"ok"}
OS 서비스로 상주 
$ damond service install  launchd / systemd user / Task Scheduler
$ damond service print
번들 웹 UI로 바로 대화

세션, 스트리밍, 권한 프롬프트까지 — 설치 불필요.

http://127.0.0.1:9470/ui

채팅 채널

채팅 앱이 곧 컨트롤 룸

각 채팅이 고유한 에이전트 세션에 매핑되고 응답은 스트리밍됩니다. tool 권한 요청은 allow/deny 답장으로 승인합니다.

Telegram 
$ damon-telegram --bot-token <token>
Discord 
$ damon-discord --bot-token <token>
Slack 
$ damon-slack --app-token xapp-… --bot-token xoxb-…

원격 접근

어디서든, 안전하게

Tailscale (권장)

ws://<tailscale-ip>:9470/ws로 attach — WireGuard E2E, 데몬 설정 변경 없음.

직접 TLS

tls_cert/tls_key로 wss 서빙. 비루프백 바인드는 auth_token 없이 기동 거부.

자체 릴레이

공개 호스트의 damon-relay로 아웃바운드 연결 — 인바운드 포트 불필요. X25519 키 교환 → AES-256-GCM, 릴레이는 평문을 볼 수 없음.
